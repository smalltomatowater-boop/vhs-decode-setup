# contrast-v7 の検証 — 色の濃さ 1.45 倍

2026-11-19。0 IRE マスター専用のコントラスト重視に、色差(U/V)の 1.45 倍を足した。
標準版(standard-v5)は触らない。黒点 137・切り出し・ノイズ処理・符号化は contrast-v5 と同一。

## 何をしたか

マスターは記録されたままを保つ。納品用 mp4 の段階で、色差を 512(無彩色)から離す。

    u,v = clip((val - 512) * 1.45 + 512, 0, 1023)

NR(hqdn3d) は掛け算のあとに置く。

## なぜ 1.45 か

RF 直取りは記録されたままを出すので、従来のキャプチャより淡く見える。
1.30 は「わかりづらい」、1.45 を採用（マスターの決定）。1.60 も見たが、
色ノイズも同じ倍率で増える。

## 測ったこと

### 1. tape05 の10場面（v5 のコマから色差だけ計算し直した）

- 明るい側の飽和（RGB が 260 超え）: 1.00 / 1.30 / 1.45 とも **全10場面で 0%**
- 暗くない画素（輝度>25）で RGB がマイナスに切られる割合
  （色が濃い場面のみ。他の8場面は 0%）

      場面1  1.00 → 0.00%   1.30 → 0.11%   1.45 → 0.51%
      場面3  1.00 → 0.05%   1.30 → 0.27%   1.45 → 0.61%

- 平坦部の色ノイズσ: 1.30 で約 1.25 倍（0.95 → 1.18 など）。倍率に比例
- 注意: 最初に「色差が 16/240 に張り付く画素」で数えて 0.00% と報告したが、
  これは甘い基準で目に見える潰れを拾えなかった。上の2指標が正しい。
  黒に近い画素のマイナスを数えると 36% などの過大な値が出る（黒に載る色ノイズ）。

### 2. 昔の USB キャプチャ(mpg)との比較 — [DIE IN CRIES]”CLIPS” 1曲目 2:49

NAS のごみ箱に残っていた 2022-01 の `.mpg`（720×480 MPEG-2）と、RF マスター(v6)の
同じカットを並べた。

- 位置合わせ: 音声の相互相関で +8.75 秒(相関 0.92 以上、20分間で揃う)、
  そこから絵の相関で −0.27 秒、相関 0.955。**昔のキャプチャは映像と音声が数秒ずれている**。
- 場面2(3:52)は探索 ±8 秒でも相関 0.459 のまま。別のカットで、**不採用**。

輝度(限定レンジ、16=黒 235=白) 1% / 5% / 中央 / 95%:

    昔の USB (mpg)         0    1   16  235   ← 黒が法定の16より下まで潰れ、白は235に張り付く
    RF 標準               23   25   39  191   ← 記録のままの黒が見える（白っぽく見える理由）
    RF コントラスト重視     16   16   17  186   ← 昔の USB の黒に近い

彩度(平均 |U-128|+|V-128|):

    昔の USB 5.9   RF ×1.00 5.5   ×1.45 8.0   ×1.60 8.8

**昔の USB のアーカイブは、RF とほぼ同じ濃さ(約 7% 濃いだけ)。** ×1.45 は昔より
約 36% 鮮やかになる。「昔の見え方に近づける」なら 1.1 前後で足りる。×1.45 は
「昔より鮮やかにする」選択として採用した。

## 使えるマスター

0 IRE マスター(VHS_BLACK_IRE=0 の印あり)のみ。7.5 IRE 時代のマスターは
vhsdeliver の安全装置が止める。彩度を足すなら contrast-v6 に足した別版が要る。
