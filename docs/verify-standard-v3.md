# profile-standard-v3 検証記録

- 検証日: 2026-11-12
- 素材: tape05r（VHS / NTSC / 7分37秒 / FANATIC◇CRISIS「Truth」）
  - tape05 と同じ物理テープを 2026-11-12 に録り直したもの。原本RFは 13,088,325,632 バイト
- 対照: `ref_tape05r.mkv`（同じ再生中に S端子から同時収録した参照キャプチャ）
- v2 からの変更: **白飛び場面で出る虹色ノイズの区間だけ彩度を0にする。他は一切同じ**

## 検証の範囲（重要）

**この記録はテープ1本・既知の異常10箇所と正常10箇所における測定値であり、
全編・全テープの品質保証値ではない。** しきい値は 360x240 / flags=neighbor
での目盛りに依存する。解像度や縮小方法を変えるなら測り直すこと。

## なぜ必要か

マスターが tape05 の納品物に乱れを見つけたのが発端。原因を追うと、
テープの傷でもデッキの不調でもなく、**RF経路が作っていた**。

| | RF経路（うちの納品物） | S端子（同じ再生の同じ瞬間） |
|---|---|---|
| 101.0s | 色差σ 33.3 | 6.9 |
| 102.0s | 色差σ 37.7 | 6.9 |
| 103.0s | 色差σ 24.5 | 6.1 |
| 104〜106s | 0.9 | 0.6 |
| 110.0s | 4.3 | 4.4 |

104〜106秒は**両方とも色が無い**。そこは本当に白飛びしている場面で、
S端子で見ると一面の白。その入口と出口で、RF経路だけが虹色に荒れる。
デッキには色が無いときに色を切る回路があり、vhs-decode には無い。

RF信号自体は無事である。0.2ms刻み・前後60msで振幅を追っても、
異常5箇所（最小21.3〜23.6）と対照3箇所（21.8〜23.8）で区別がつかない。
ドロップアウトなら必ず振幅の谷になるが、ならない。

## 色の復号段は無罪

`--chroma-decoder` を `ntsc3d` から `ntsc2d` に変えて同じTBCから書き出し、
同じ時刻で比較した。

| 時刻 | ntsc3d | ntsc2d | S端子 |
|---|---|---|---|
| 101.0s | 33.3 | 34.1 | 6.9 |
| 192.0s | 36.6 | 37.5 | 5.2 |
| 245.0s | 34.9 | 36.8 | 5.6 |

S端子から8以上ずれたコマは **ntsc3d 10個 / ntsc2d 10個** で同数。
時間方向のフィルタが原因ではない。よって色の復号段では直せない。
納品段で消すのが現実的な対処になる。

## 検出のしきい値

2つ測り、両方を満たすコマだけを対象にする。「いろどり」だけで切ると
本当に色鮮やかな場面を巻き添えにするため、「ざらつき」を併用する。

| | いろどり（色差の標準偏差） | ざらつき（横に隣り合う画素の色差の差） |
|---|---|---|
| 既知の異常10コマ | 24.4 〜 55.0 | 2.6 〜 10.0 |
| 既知の正常10コマ | 3.5 〜 8.9 | 0.7 〜 0.9 |
| 採用したしきい値 | **15.0** | **1.6** |

どちらも約3倍の谷が空く。しきい値はその谷の中に置いた。
全編の分布もこれを裏づける（いろどり 90%点 12.8 → 95%点 44.3、
ざらつき 90%点 0.97 → 95%点 6.91。90%と95%の間が空洞）。

該当区間は **18件 / 計45.4秒 / 本編457秒の 9.93%**。

## 結果

### 修復の効き（中間 video.mkv で確認）

| 時刻 | 修復前 | 修復後 |
|---|---|---|
| 100.0s | 35.92 | **0.00** |
| 101.0s | 24.07 | **0.00** |
| 102.0s | 38.42 | **0.00** |
| 103.0s | 27.81 | **0.00** |
| 97〜99s / 104〜106s | — | **値が1つも動かない** |

絵でも確認した。虹色のゴミだったコマが、中身の読み取れるモノクロになる。

### 最終納品物での確認（vhsdeliver standard-v3 を通した出力）

| | 測った箇所 | 色差σ | 結果 |
|---|---|---|---|
| 修復区間 | 9箇所 | 0.41 〜 0.68 | 色が抜けている |
| 正常区間 | 11箇所 | 2.52 〜 7.51 | 色が残っている |

**修復もれ 0 件、正常部の巻き添え 0 件。**

### v2 との同一性

`BLACK` / `CROP` / `SCALE` / `DEINTERLACE` / `VCODEC` / `VTAGS` /
`ACODEC` / `MUXOPT` の **8項目すべて一致**。変わるのは彩度を0にする
区間フィルタが `NR` の前に入ることだけ。

### 自動検査（vhsverify）

映像側は全項目合格（H.264 / yuv420p / color_range=tv / 640x480 /
59.94fps / データトラック無し / faststart / 全編の復号でエラー無し）。
音声関係5項目は不合格だが、これは検証に無音の中間ファイル `video.mkv` を
入力に使ったためで、プロファイルとは関係ない。

## 運用上の決まり

区間はテープごとに違うので、プロファイルには焼き込まない。
`VHS_CHROMA_JSON` が指すファイル（`bin/vhschroma.py` が作る）から読む。

- `VHS_CHROMA_JSON` 未設定 → **止まる**
- ファイルが存在しない → **止まる**

黙って未修復を納品しないため、どちらも警告ではなく停止にしてある。
