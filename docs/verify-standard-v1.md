# profile-standard-v1 検証記録

- 検証日: 2026-11-02
- 素材: tape01（VHS / NTSC / 28分27秒 / ビジュアル系PV集）
- 保存マスター: `完成_tape01.mkv`（FFV1 yuv422p10le フルレンジ 19GB）
- 納品物: `納品_標準_tape01.mp4`（H.264 CRF18 / 784MB）

## 検証の範囲（重要）

**この記録は3つの代表場面における測定値であり、テープ全編の品質保証値ではない。**
別のテープ、別の場面では異なる結果になりうる。次のテープでも同じ検証を行い、
素材の状態が変わっても設定が破綻しないかを確認すること。

検証した場面:

| 場面 | 時刻 | 選んだ理由 |
|---|---|---|
| 黒シルエット・雪原 | 651.5s | 黒い人物が明るい背景に乗る。黒つぶれが出やすい |
| 黒スーツ・白壁 | 653.5s | 暗部と白飛びが同一画面に同居する最も厳しい条件 |
| 暗い室内 | 630.0s | 全体が暗く、階調が詰まっている |

## 工程の分離

4段階を同一条件（640x480 / 8bit / リミテッド符号化）に揃えて比較した。

| 段階 | 内容 |
|---|---|
| A | 無加工（解除・切り出し・フル→リミテッド変換のみ） |
| B | A + 黒点68 |
| C | B + hqdn3d（符号化前の最終状態） |
| D | 最終MP4 |

## 結果

### 構造の損失（画面全体に対する実数）

| 場面 | A | B | C | D |
|---|---|---|---|---|
| 黒シルエット・雪原 | 0.0000% | 0.0157% | 0.0092% | 0.0279% |
| 黒スーツ・白壁 | 0.0000% | 0.0388% | 0.0448% | **0.0668%** |
| 暗い室内 | 0.0000% | 0.0000% | 0.0000% | 0.0000% |

「構造」= 黒つぶれ（Y≤16）した画素のうち、水平方向に10画素以上連続しているもの。
孤立した1〜2画素はノイズの谷であり、構造ではない。

### 白飛び

全段階・全場面で 0.001〜0.020%。白壁の階調（壁の角・段差・床・周辺減光）は
ハイライト拡大表示で4段階すべてに残存を確認。

### ノイズ

黒点補正はノイズを `1023/(1023-68)` = **1.0712倍** に増幅する（数学的帰結）。
hqdn3d がこれを相殺し、最終的な無加工比は **-2.3% 〜 +7.8%**。

### 符号化の忠実度（C→D）

| 場面 | SSIM | PSNR |
|---|---|---|
| 黒シルエット・雪原 | 0.9694 | 40.94 dB |
| 黒スーツ・白壁 | 0.9743 | 43.49 dB |
| 暗い室内 | 0.9613 | 41.48 dB |

ラプラシアン応答（細部）は C→D で大きく下がるが、SSIM/PSNR が上記の水準で
あることから、構造の喪失ではなくノイズの減少によるものと判断した。

### 音声

マスターとの波形相関 0.9961〜0.9977、ずれ ±32ms、ドリフトなし。
32ms は測定の粒度（AAC の符号化遅延）であり、知覚閾値の内側。

### 再生互換性

H.264 High@L3.1 / yuv420p / AAC-LC 48kHz ステレオ / faststart（moov先頭）。
全編の復号でエラー 0 件。

## 測定指標の限界

- **暗部の階調数 / ハイライトの階調数は飽和して使えなかった。** A/B/C がいずれも
  測定帯の全階調（63/63、53/53）を占有したため段階間の比較ができない。
  D のみ 54/45 に低下しており、これは 8bit 量子化の影響。
- **時間ノイズは被写体の動きを含む。** 黒シルエット場面の 17 以上という値は
  大半が動きであり、ノイズの量ではない。

## 既知の指摘（v1 では未対応）

`tmcd`（QuickTime タイムコードトラック）が ffmpeg により自動付与される。
主要プレーヤーは無視するため実害は確認されていないが、納品にタイムコードは
不要。`-write_tmcd 0` で抑止できる。**v1 の検証はこれを付けない状態で行ったため
v1 には入れず、standard-v2 として別途評価する。**

既存ファイルを直す場合は再エンコードせず、映像・音声をストリームコピーして
別ファイルにリマックスし、`bin/vhsverify` で再確認すること。
